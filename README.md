# EPBL - Vehicle Management System

This repository contains the complete documentation and project files for the **Vehicle Management System** developed as part of the Engineering Project Based Learning (EPBL) course.

## 📁 Project Structure

- **Assignments/** - Course assignments and deliverables
- **Doc and Demo/** - Project documentation and demo videos
- **Functional and Performance Testing/** - Testing documentation
- **Ideation Phase/** - Initial project ideation documents
  - Empathy Map Canvas
  - Problem Statements
  - Brainstorming materials
- **Project Design Phase/** - Design and architecture documents
  - Solution Architecture
  - Problem-Solution Fit
  - Proposed Solution
- **Project Planning Phase/** - Project planning templates and schedules
- **Project Executable Files/** - Output and executable files
- **Requirement Analysis/** - Requirements documentation
  - Data Flow Diagrams
  - User Stories
  - Customer Journey Map
  - Technology Stack
  - Solution Requirements
